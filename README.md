# 动手学深度学习（个人学习笔记）

基于《动手学深度学习》v2，**不使用 `d2l` 包**，全部用 PyTorch 原生 API 实现。

## 环境

- Ubuntu 24.04 / Python 3.12 / CUDA 13.0
- PyTorch + torchvision + torchaudio
- VSCode + Jupyter 扩展

## 目录

- `notebooks/` — 按章节手敲的笔记
- `utils/`    — 自己写的复用函数（替代 d2l 包）
- `data/`     — 数据集（不提交）
- `models/`   — 保存的权重（不提交）
